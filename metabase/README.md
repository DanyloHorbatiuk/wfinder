# Metabase — заготовка дашбордів (E-09)

SQL-запити тут — нативні (native/SQL question), готові для копіювання в Metabase.
Створення самих карток і дашбордів у Metabase — ручна робота в інтерфейсі
(SPEC §12.1: "поки що створюються вручну"); автоматизація через
`scripts/metabase_provision.py` — окремий пункт E-10 (фаза 2), відкладений
до появи цих двох дашбордів і живого Metabase для звірки API (див.
журнал рішень у `ROADMAP.md`).

## Як створити питання

1. У Metabase: **New → SQL query**, обрати підключення "WorkFinder" (Postgres).
2. Вставити текст із відповідного файлу `cards/NN_name.sql`.
3. Поля виду `{{source}}`, `{{start_date}}`, `{{end_date}}` Metabase сама
   розпізнає як змінні питання й запропонує створити відповідні фільтри
   (Field Filter або Text/Date). Синтаксис `[[AND source = {{source}}]]`
   робить фільтр опційним — картка працює і без нього.
4. Зберегти питання під назвою з таблиці нижче, додати до відповідної колекції.
5. Зібрати два дашборди (розділ нижче), додати фільтри на рівні дашборду
   (`source`, `period`) і прив'язати їх до карток, що приймають ці змінні.

## Перевірка запитів

Кожен файл перевірено локально проти реальних даних I-01 (без Docker,
`sql/views/*.sql` застосовано через `scripts/apply_views.py`) — усі 12
виконуються без помилок. Питання 7/8/11 повертали 0 рядків на тестовому
наборі — це очікувано (немає закритих не-left-censored епізодів чи
помилок/блокувань у тому наборі), а не ознака зламаного запиту.
